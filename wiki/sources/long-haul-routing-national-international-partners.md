## Summary

Scope analysis for long haul routing rule sets, particularly how the existing `INTERNATIONAL` / `NATIONAL` ruleset typing maps to the organizational responsibility model (GLS International vs Partner). Proposes renaming the existing types to clarify intent: `INTERNATIONAL` -> `INTERNATIONAL_LH_MGMT` (created by GLS International), `NATIONAL` -> `PARTNER_LH_MGMT` (created by a partner, where next location must belong to that partner), and adding a `SYSTEM` type. Rule sets are evaluated in this order: SYSTEM, INTERNATIONAL_LH_MGMT, PARTNER_LH_MGMT.

## Key Claims

- A route is INTERNATIONAL if origin country code != final country code; NATIONAL if they are equal. This is the routeType.
- A route step is INTERNATIONAL if source-location country != next-location country; NATIONAL if equal.
- A routing rule set is defined for a source location.
- Multiple rule sets per source location can exist - generated by different parties (partner or GLS International) for different purposes.
- Existing `ruleSetType` values (INTERNATIONAL / NATIONAL) describe the originator and constraints, not the routing type.
- Proposed rename: `ruleSetType` -> `rulesetOriginator`; INTERNATIONAL -> INTERNATIONAL_LH_MGMT; NATIONAL -> PARTNER_LH_MGMT; add SYSTEM.
- Application order: SYSTEM -> INTERNATIONAL_LH_MGMT -> PARTNER_LH_MGMT.
- Current optimization skips INTERNATIONAL ruleset evaluation when source and final locations share owner/country; this skip needs re-evaluation if INTERNATIONAL also defines routes within a partner or going via a different partner.

## Evidence and Notes

- Open question: should the constraint "next location must have different owner than source location" apply to INTERNATIONAL_LH_MGMT? Author suggests removing the restriction.
- Open question: should PARTNER_LH_MGMT next location be in the same country as the source, or only same owner?
- Open question: tagging rulesets to indicate same-vs-different-partner / same-vs-different-country for next location?
- Note: Questions in the source are unresolved as of writing.
