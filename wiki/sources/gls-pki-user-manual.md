## Summary

The GLS PKI User Manual is the top-level index for all PKI documentation maintained by Information Security Germany. It acts as a table of contents linking to five operational guides and a FAQ, all hosted on the GLS Confluence space. The underlying PKI portal is at pki.gls-group.net.

## Key Claims

- The PKI documentation set covers five topic areas: certificate request, renewal, revocation, User/SMIME Outlook configuration, and a FAQ.
- All procedures are executed via the production portal at pki.gls-group.net.
- Documentation is published under the GLS Information Security Germany Confluence space (ISG).

## Evidence and Notes

- Child pages listed in the manual: Certificate Request Guide, Renewal Guide, Revocation Guide, User/SMIME Certificate Outlook Configuration, GLS PKI FAQ.
- Published Dec 15, 2022.
